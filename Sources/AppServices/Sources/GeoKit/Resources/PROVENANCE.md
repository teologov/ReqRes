# GeoKit resources — provenance

Every file in this directory is GENERATED by `Scripts/geo/build-geo-resources.py`
from the public sources below. Do not edit them by hand: `--check` fails the
GeoKit test suite if a file is not exactly what the converter emits.

  (repository `eggert/tz`, `main` at commit `cd706278466a`, 2026-09-22)

  can still return them. 549 rows.

## Centroids

One point per ISO code, `[lat, lon]`:

- 175 computed from the outlines: the area centroid of the country's largest
  polygon. The converter checks every point against its own outline and refuses
  to build if one is outside and not in `HAND_FIXED`. Currently hand-fixed:
  HR, HT, IL, NO, VN (centroid outside the outline) and ID, MY (the largest
  polygon is the wrong island). The reasons are in the converter next to the
  numbers.
- 75 hand-placed (`HAND_PLACED` in the converter) for countries DB-IP knows
  that have no polygon at 1:110m — Singapore, Hong Kong, Malta, Bahrain, the
  Channel Islands, the Caribbean and Pacific islands. Approximate, world-map
  precision only.

## Binary format decision

Fixed rows of (start, end, country u16) would take 15.8 MB for this data,
against a budget of ~3 MB for the whole addition. DB-IP's table is
contiguous (gaps are explicit `ZZ` rows), so each row's end is the next row's
start − 1 and only starts need storing; those are delta-encoded as LEB128
varints with a 2-bit tag selecting a shift (IPv4: 24/16/8/0 bits, IPv6:
96/80/64/0 — 98% of IPv6 rows are /48-aligned), and the country index is one
byte (251 codes). A fixed index entry every 64 rows keeps lookups a binary
search plus at most 63 varint decodes. Full layout in the converter's
docstring; the Swift reader is `IPCountryTable`.

## Regenerating

```sh
python3 Scripts/geo/build-geo-resources.py --download /path/to/sources --month YYYY-MM
python3 Scripts/geo/build-geo-resources.py --build --sources /path/to/sources
python3 Scripts/geo/build-geo-resources.py --check --sources /path/to/sources
```

Then update the month, SHA-256s and dates in this file (`--check` fails if the
month here does not match the binary's header), and run
`swift test --package-path Sources/AppServices --filter GeoKitTests`.
